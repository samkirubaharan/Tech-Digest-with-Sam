## Byline

Graphify is worth your attention — an extended version of Karpathy's knowledge workflow, now open source and runnable in a single command. Karpathy had been manually piping papers, tweets, and screenshots into an LLM-compiled wiki, navigated through Obsidian. Knowledge that compounds every time you add something new. His closing line: *"I think there is room here for an incredible new product instead of a hacky collection of scripts."* Graphify shipped days later.

For real work though, I prefer building it bottom-up — starting from nothing and adding only the minimum required.

That's what my KB skill set does. Three skills, one loop:

- **KB Gather** — pulls from JIRA tickets, web pages, documents (Word, Excel, PowerPoint), codebase, and chat/call transcripts including LLM conversations — and writes everything into a folder of markdown files
- **KB Consult** — attaches relevant KB topics to an active chat session for Q&A and context enrichment. Detaches when you're done
- **KB Digest** — takes new things learned during a session and writes them back into the KB

**The magic is in running it iteratively on the same data.** Each pass, the KB gets more accurate. Connections sharpen. Gaps fill in. The LLM indexes the knowledge and renders only what's relevant when it's needed — no bloat, no noise.

This is the core of what Karpathy was after: **knowledge that compounds.** Every ticket, every doc, every conversation makes the next one sharper.

Simple to build, lightweight to run — and surprisingly effective. The bigger frameworks have their place, but for a developer deep in daily work, this kind of minimal loop often does more than you'd expect from something so lean.
