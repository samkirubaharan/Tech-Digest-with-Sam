## Incoming

Anthropic just dropped three things in close succession — and together they point at something bigger than any single release.

Here's what landed:

- **Claude Opus 4.7** — the new flagship model. Stronger agentic coding scores, built-in output verification before it reports back, 3x higher image resolution, and meaningfully better at following complex instructions
- **Claude Code Routines** — scheduled, API-triggered, and GitHub-triggered automation that spins up Claude Code Web instances autonomously. No machine needs to stay awake. No IDE required
- **Redesigned Claude desktop app** — rebuilt from the ground up for parallel work. Integrated terminal, in-app file editing, rebuilt diff viewer, side chats, SSH connections

**The throughline: Anthropic isn't building a better chatbot. They're building a software development operating system.**

Routines is the one I keep thinking about. The old Schedules feature required your machine to be running. Routines runs entirely via Claude Code Web — so you can trigger nightly issue triage, PR reviews, alert triage, or cross-repo SDK ports without any local infra. That's IDE-less development becoming genuinely viable, not just a talking point.

And Opus 4.7 verifying its own outputs before surfacing results? That's not a small tweak — it's Anthropic baking epistemic discipline into the model itself rather than leaving it to prompt engineering.

At some point "AI coding assistant" stops being an accurate frame. We're already past it.
