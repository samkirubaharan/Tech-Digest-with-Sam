## Byline

Anthropic just released a redesigned Claude Desktop app — and honestly, this one's personal.

I've been running Warp terminal for a while now. The reason? It gave me a terminal, a file viewer, and a diff viewer all in one place. That's it. That's the whole reason. Switching between tools mid-flow is where I lose the thread, and Warp solved that for me.

Claude Desktop's new release does the same thing:

- **Integrated terminal** — right there in the app
- **In-app file editing** — open and edit without jumping out
- **Rebuilt diff viewer** — see what changed, properly rendered
- **Side chats** — parallel conversations for parallel work
- **SSH connections** — into remote environments directly from the app

Glad Anthropic shipped this. It's the setup I already wanted, now built into the tool I'm already using most.

If you're a developer and you haven't updated yet — worth doing today.
